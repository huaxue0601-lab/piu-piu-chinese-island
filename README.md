## 打开方式

直接打开 `index.html` 即可使用。为保证浏览器语音和本地存储表现一致，也可以在本目录启动静态服务器：

```bash
python3 -m http.server 4317
```

然后访问 `http://127.0.0.1:4317`。

## 发布到公网

项目已配置 GitHub Pages 自动部署。推送到 GitHub 仓库的 `main` 分支后，`.github/workflows/pages.yml` 会自动发布 HTTPS 网站。公开地址通常为：

公开学习地址：<https://huaxue0601-lab.github.io/piu-piu-chinese-island/>

源码仓库：<https://github.com/huaxue0601-lab/piu-piu-chinese-island>

GitHub Pages 的 HTTPS 环境支持录音权限。生词和录音保存在当前浏览器：生词可随进度 JSON 导出，录音文件只保留在录制设备上。

## 内容原则

课程整体按照以下阶段组织：

`拼音与发音 → 笔画与认字 → 词语与句子 → 生活对话 → 听读与表达`

每项学习内容预留中文读音、拼音标注和泰语解释。当前拼音阶段不考汉字，认字阶段不提前要求完整生活对话。

拼音墙和声调区优先播放随网页提供的固定普通话 MP3，音频不可用时回退到设备语音；其他课程内容目前调用设备自带的普通话语音。正式长期使用时，建议保持现有文件名和数据结构，逐项替换为真人普通话录音。

## 教研依据

- 教育部、国家语委《国际中文教育中文水平等级标准》（GF 0025-2021）：以音节、汉字、词汇、语法和真实交际任务组织学习进阶。
- Thai learners of Mandarin pronunciation 相关研究：泰语母语者不能把泰语声调与普通话声调一一对应，应重点练音高范围、第三声、送气对立、卷舌音、ü 及 `-n/-ng`。
- 课程设计采用“先听辨、再模仿、进入词块、完成真实任务”的顺序，避免把拼音长期停留在字母表层面。

资料链接：

- http://www.moe.gov.cn/jyb_sjzl/ziliao/A19/202111/W020211118507389477190.pdf
- https://www.isca-archive.org/tai_2023/li23_tai.pdf

独立游戏中心作为备用游戏库保留；正式上课优先使用课程详情中标注“讲到这里就玩”和“准备输出前玩”的活动。

纠错遵守三条规则：不在表达中途打断、一次最多纠正两处、优先处理影响理解的问题。
